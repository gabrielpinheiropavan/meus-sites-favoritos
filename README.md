# Meus Sites Favoritos 🍷

Projeto desenvolvido como atividade de recuperação da Agenda 12 do curso Técnico em Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O projeto consiste em uma página web que apresenta cinco dos meus sites favoritos, utilizando HTML5 e CSS3.

A página possui uma identidade visual escura, com detalhes em vinho e bordô, cartões individuais e efeitos de interação.

## 🌐 Sites apresentados

- YouTube
- Spotify
- Wikipedia
- Letterboxd
- Skoob

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Exibição de cinco sites favoritos.
- Imagens representativas de cada plataforma.
- Links para acessar os sites em novas abas.
- Cartões com bordas arredondadas.
- Efeitos visuais ao passar o mouse.
- Layout responsivo utilizando CSS Grid.

## 📂 Estrutura do projeto

```text
meus-sites-favoritos/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
